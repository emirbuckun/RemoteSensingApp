# RemoteSensingApp
CSE4074 Computer Network Programming Assignment: Remote Sensing Application

## Techs
The project basically consists of four different parts.<br>
All development was done with the .NET 7.0 version.<br>
You should install that version to your computer to run the project.<br>
Link: https://dotnet.microsoft.com/en-us/download/dotnet/7.0

## How to run
To run each console application you should run the below commands inside solution directory in different terminals respectively:

```
dotnet restore
```

```
dotnet run --project RemoteSensingApp.HttpServer
```
```
dotnet run --project RemoteSensingApp.Gateway
```
```
dotnet run --project RemoteSensingApp.SensorTemp
```
```
dotnet run --project RemoteSensingApp.SensorHum
```
